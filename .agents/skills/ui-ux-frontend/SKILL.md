name: ui-ux-frontend
description: Improve and implement modern, responsive, accessible, and consistent user interfaces in existing web applications. Use this skill when working on UI, UX, frontend components, layouts, navigation, responsive design, animations, interactions, styling, accessibility, or visual improvements, especially in web and full-stack projects.

First inspect the existing frontend structure, components, styling system, design patterns, routes, and reusable UI elements. Reuse existing components and styles whenever possible.

Make only the UI changes requested by the user. Do not create new pages, features, or unrelated components unless they are genuinely required. Preserve existing functionality and routing.

Use clean responsive layouts, consistent spacing, typography, states, hover interactions, loading states, error states, and accessible interactions when appropriate. Keep animations smooth and purposeful rather than excessive.

After changes, verify the affected UI across relevant screen sizes and make sure the application still builds and works correctly.

Keywords: UI, UX, frontend, web design, responsive design, accessibility, components, layout, navbar, navigation, animations, transitions, hover, styling, CSS, HTML, JavaScript, React, web app, mobile responsive, user interface, user experience.
